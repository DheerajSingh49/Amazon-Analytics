# Amazon Product Analytics

## Project Overview

This is an end-to-end Data Analytics project built using PostgreSQL and Power BI. The project focuses on cleaning raw Amazon product data, performing SQL analysis, and creating an interactive dashboard to analyze product performance, pricing, discounts, and customer ratings.

## Objectives

- Clean and transform raw product data
- Perform SQL-based exploratory analysis
- Create business-ready features
- Build an interactive Power BI dashboard
- Generate actionable business insights

## Dataset

The dataset contains Amazon product information, including product details, categories, prices, discounts, ratings, rating count, and customer reviews.

## Key Insights

- Electronics has the highest number of products.
- Most products fall within the medium to high discount range.
- Customer ratings remain consistently high across categories.
- Higher discounts do not necessarily lead to better ratings.
